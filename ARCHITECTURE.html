AntDongle virtual trainer: architecture

Flask server + browser 3D view that turns a real bike on an Elite Qubo trainer into a virtual ride. Derived from HANDOVER.md and the code in the project folder (as of 2026-11-01).

5. Runtime flows

Two flows matter most: the sensor path (how a sample becomes a HUD number) and the start-ride sequence.

5a. Sensor sample to screen

sequenceDiagram
  autonumber
  participant HW as ANT stick / BLE
  participant SES as AntSession (reader thread)
  participant SR as SensorRoles
  participant RE as RideEngine (thread)
  participant RS as RideState
  participant PH as RoadPhysics + TrainerPowerModel
  participant API as Flask /api/stream (SSE)
  participant UI as Browser (hud.js, world.js)

  HW->>SES: broadcast pages (HR, speed, cadence)
  SES->>SES: decode via profiles.Decoder
  SES-->>RE: publish Sample to subscriber queue
  RE->>SR: which device feeds which role
  RE->>RS: measured speed, HR, cadence
  RS->>PH: power absorbed at measured speed
  PH-->>RS: virtual speed, distance, power
  RS->>RS: gearing (only without cadence sensor)
  RE->>API: tick (snapshot)
  API-->>UI: SSE event
  UI->>UI: update HUD tiles, move rider and ghosts

5b. Start a workout ride

sequenceDiagram
  autonumber
  actor R as Rider
  participant P as ride.html / main.js
  participant A as app.py
  participant W as workout.py
  participant E as RideEngine
  participant REC as recorder.py

  R->>P: choose workout, preset, ghost mode
  P->>A: POST /api/workout (shorthand or fields)
  A->>W: Workout(...) / parse_shorthand
  W-->>A: to_dict()
  A-->>P: workout profile (table, gradients)
  R->>P: press start (start gate)
  P->>A: POST /api/ride/start
  A->>E: start thread
  E->>REC: open recordings/<timestamp>/
  loop every tick
    E->>E: consume samples, update RideState
    E-->>P: SSE /api/stream
  end
  R->>P: stop
  P->>A: POST /api/ride/stop
  A->>E: stop, close files
  E->>REC: ride.csv, ride_clean.csv, samples.csv, session.json

6. HTTP API (Flask, app.py)

Grouped by area. All JSON unless noted. SSE is a server-sent event stream.

AreaRoutesPurpose
PagesGET /, /ride, /history Debug UI, ride page. /history is registered, but static/history.html does not exist yet.
Device/api/connect, /api/disconnect, /api/reset, /api/scan, /api/stop, /api/send ANT stick lifecycle, raw scan and send for debugging.
Sensors/api/sensors, /search, /select, /reset Channel search and pairing; sensor role selection.
BLE/api/ble/scan, /start, /stop, /state Watch heart rate via bleak.
WorkoutGET/POST /api/workoutBuild and read the interval workout.
Ride/api/ride/start, /pause, /resume, /stop, GET /state Control the RideEngine.
RecordingsGET /api/rides, GET /api/rides/<id>/<file>, GET /api/export.csv List and download recorded rides.
ConfigGET/POST /api/configReads config.json (wheel circumference, gradients).
TestingGET/POST /api/test/speed-multiplier Fake speed sensor multiplier (currently ×5 at runtime, resets to ×1 on restart).
StreamGET /api/stream SSELive ride ticks to the browser.

7. Tools and libraries

Python runtime

  • Python 3.11
  • Flask (>= 3.0): web server, routes, SSE
  • pyusb (>= 1.2): USB access to the ANT stick (libusb-win32 driver, libusb0.dll)
  • bleak: Bluetooth LE heart-rate client
  • numpy, matplotlib, pillow: analysis and plots
  • esprima: syntax check of page JS only (no ?. / ??)
  • unittest: test runner (python -m unittest discover -s tests)

Browser

  • ES modules (no bundler, no build step)
  • Three.js r170, vendored in static/vendor/
  • EventSource (SSE) for live ticks
  • Web Audio via audio.js for beeps
  • Plain HTML/CSS layout (no framework)

Hardware and protocols

  • ANT USB Stick 2, ANT 2.4 GHz, up to 8 channels
  • ANT+ profiles: heart rate (type 120), speed (type 123)
  • Bluetooth LE heart rate via laptop adapter
  • Elite Qubo Power Fluid trainer (power model fitted to 2 points + manufacturer chart)
  • Dynastream libusb-win32 driver

Models and assumptions

  • Road physics: mass 76 kg, Crr 0.005, CdA 0.32 m² (guess), rho 1.2
  • Virtual gearing: 34/50T front, 11-34 rear, 13 usable gears, cadence band 85-100 rpm, target 92.5 rpm
  • Wheel circumference 2.105 m (28" x 30 mm)
  • Chainstay 405 mm and wheelbase 1010 mm (estimates)
